# Project Documents

இந்த `docs/` folder-ல் Class 1–12 அனைத்துக்கும் பொதுவான project rules உள்ளன.

## பொதுவான நடைமுறை ஆவணங்கள்

- [PROJECT_BLUEPRINT_COMMON_TA.md](./PROJECT_BLUEPRINT_COMMON_TA.md) — Book Back question checking, One-mark answer verification, four-option Quiz, Unit JSON, Master Quiz QA.
- [BOOK_EDITION_VERIFICATION_RULES_TA.md](./BOOK_EDITION_VERIFICATION_RULES_TA.md) — ஒவ்வொரு Class / Subject / Medium / Term / Volume-க்கும் தனித்தனியாகப் புத்தகப் பதிப்பைச் சரிபார்க்கும் விதிகள்.

## ஆவணங்களைப் பயன்படுத்தும் விதி

- இந்த இரண்டு ஆவணங்களும் Class 1–12 repositories-ல் ஒரே மாதிரியாக இருக்க வேண்டும்.
- `docs/`-ல் ஏற்கெனவே உள்ள class-specific audit reports, manifests, refresh evidence ஆகியவற்றை அழிக்கவோ மாற்றவோ வேண்டாம்.
- Class / Subject / Medium / Term-க்கான தனிப்பட்ட audit முடிவுகளை அதற்குரிய repository-யிலேயே பதிவு செய்யவும்.
- பொதுவான workflow மாற வேண்டுமெனில், எல்லா class repositories-க்கும் ஒரே change-ஆக ஒத்திசைக்கவும்.
