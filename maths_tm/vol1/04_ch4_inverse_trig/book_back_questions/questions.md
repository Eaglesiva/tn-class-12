### கொடுக்கப்பட்ட நான்கு மாற்று விடைகளிலிருந்து சரியான அல்லது மிகவும் ஏற்புடைய விடையினைத் தேர்ந்தெடுக்கவும்.

1. $\sin^{-1}(\cos x)$-ன் மதிப்பு, $0 \leq x \leq \pi$
   அ) $\pi - x$
   ஆ) $x - \frac{\pi}{2}$
   இ) $\frac{\pi}{2} - x$
   ஈ) $x - \pi$

2. $\sin^{-1} x + \sin^{-1} y = \dfrac{2\pi}{3}$ எனில், $\cos^{-1} x + \cos^{-1} y$-ன் மதிப்பு
   அ) $\frac{2\pi}{3}$
   ஆ) $\frac{\pi}{3}$
   இ) $\frac{\pi}{6}$
   ஈ) $\pi$

3. $\sin^{-1}\dfrac{3}{5} - \cos^{-1}\dfrac{12}{13} + \sec^{-1}\dfrac{5}{3} - \operatorname{cosec}^{-1}\dfrac{13}{12}$-ன் மதிப்பு
   அ) $2\pi$
   ஆ) $\pi$
   இ) $0$
   ஈ) $\tan^{-1}\frac{12}{65}$

4. $\sin^{-1} x = 2\sin^{-1}\alpha$ எனும் சமன்பாட்டிற்கு ஒரு தீர்வு இருந்தால், பின்னர்
   அ) $|\alpha| \leq \frac{1}{\sqrt{2}}$
   ஆ) $|\alpha| \geq \frac{1}{\sqrt{2}}$
   இ) $|\alpha| < \frac{1}{\sqrt{2}}$
   ஈ) $|\alpha| > \frac{1}{\sqrt{2}}$

5. பின்வரும் எம்மதிப்புகளுக்கு $\sin^{-1}(\cos x) = \dfrac{\pi}{2} - x$ மெய்யாகும்
   அ) $-\pi \leq x \leq 0$
   ஆ) $0 \leq x \leq \pi$
   இ) $-\frac{\pi}{2} \leq x \leq \frac{\pi}{2}$
   ஈ) $-\frac{\pi}{4} \leq x \leq \frac{3\pi}{4}$

6. $\sin^{-1} x + \sin^{-1} y + \sin^{-1} z = \dfrac{3\pi}{2}$ எனில், $x^{2017} + y^{2018} + z^{2019} - \dfrac{9}{x^{101} + y^{101} + z^{101}}$-ன் மதிப்பு
   அ) $0$
   ஆ) $1$
   இ) $2$
   ஈ) $3$

7. சில $x \in \mathbb{R}$-க்கு $\cot^{-1} x = \dfrac{2\pi}{5}$ எனில், $\tan^{-1} x$-ன் மதிப்பு
   அ) $-\frac{\pi}{10}$
   ஆ) $\frac{\pi}{5}$
   இ) $\frac{\pi}{10}$
   ஈ) $-\frac{\pi}{5}$

8. $f(x) = \sin^{-1}\sqrt{x - 1}$ என வரையறுக்கப்படும் சார்பின் சார்பகம் (domain)
   அ) $[1, 2]$
   ஆ) $[-1, 1]$
   இ) $[0, 1]$
   ஈ) $[-1, 0]$

9. $x = \dfrac{1}{5}$ எனில், $\cos\left(\cos^{-1} x + 2\sin^{-1} x\right)$-ன் மதிப்பு
   அ) $-\sqrt{\frac{24}{25}}$
   ஆ) $\sqrt{\frac{24}{25}}$
   இ) $\frac{1}{5}$
   ஈ) $-\frac{1}{5}$

10. $\tan^{-1}\left(\dfrac{1}{4}\right) + \tan^{-1}\left(\dfrac{2}{9}\right)$-ன் மதிப்பு சமம்
   அ) $\frac{1}{2}\cos^{-1}\left(\frac{3}{5}\right)$
   ஆ) $\frac{1}{2}\sin^{-1}\left(\frac{3}{5}\right)$
   இ) $\frac{1}{2}\tan^{-1}\left(\frac{3}{5}\right)$
   ஈ) $\tan^{-1}\left(\frac{1}{2}\right)$

11. சார்பு $f(x) = \sin^{-1}\left(x^{2} - 3\right)$ எனில், $x$ இருக்கும் இடைவெளி
   அ) $[-1, 1]$
   ஆ) $\left[\sqrt{2}, 2\right]$
   இ) $\left[-2, -\sqrt{2}\right] \cup \left[\sqrt{2}, 2\right]$
   ஈ) $\left[-2, -\sqrt{2}\right]$

12. $\cot^{-1} 2$ மற்றும் $\cot^{-1} 3$ ஆகியன ஒரு முக்கோணத்தின் இரு கோணங்கள் எனில், மூன்றாவது கோணமானது
   அ) $\frac{\pi}{4}$
   ஆ) $\frac{3\pi}{4}$
   இ) $\frac{\pi}{6}$
   ஈ) $\frac{\pi}{3}$

13. $\sin^{-1}\left(\tan\dfrac{\pi}{4}\right) - \sin^{-1}\left(\sqrt{\dfrac{3}{x}}\right) = \dfrac{\pi}{6}$ எனில், $x$ என்பது பின்வரும் சமன்பாட்டின் மூலமாகும்
   அ) $x^{2} - x - 6 = 0$
   ஆ) $x^{2} - x - 12 = 0$
   இ) $x^{2} + x - 12 = 0$
   ஈ) $x^{2} + x - 6 = 0$

14. $\sin^{-1}\left(2\cos^{2} x - 1\right) + \cos^{-1}\left(1 - 2\sin^{2} x\right) =$
   அ) $\frac{\pi}{2}$
   ஆ) $\frac{\pi}{3}$
   இ) $\frac{\pi}{4}$
   ஈ) $\frac{\pi}{6}$

15. $\cot^{-1}\left(\sqrt{\sin\alpha}\right) + \tan^{-1}\left(\sqrt{\sin\alpha}\right) = u$ எனில், $\cos 2u$-ன் மதிப்பு
   அ) $\tan^{2}\alpha$
   ஆ) $0$
   இ) $-1$
   ஈ) $\tan 2\alpha$

16. $|x| \leq 1$ எனில், $2\tan^{-1} x - \sin^{-1}\dfrac{2x}{1 + x^{2}}$-ன் மதிப்பு சமம்
   அ) $\tan^{-1} x$
   ஆ) $\sin^{-1} x$
   இ) $0$
   ஈ) $\pi$

17. $\tan^{-1} x - \cot^{-1} x = \tan^{-1}\left(\dfrac{1}{\sqrt{3}}\right)$ என்ற சமன்பாட்டிற்கு
   அ) தீர்வு இல்லை
   ஆ) ஒரேயொரு தீர்வு
   இ) இரு தீர்வுகள்
   ஈ) எண்ணற்றத் தீர்வுகள்

18. $\sin^{-1} x + \cot^{-1}\left(\dfrac{1}{2}\right) = \dfrac{\pi}{2}$ எனில், $x$-ன் மதிப்பு
   அ) $\frac{1}{2}$
   ஆ) $\frac{1}{\sqrt{5}}$
   இ) $\frac{2}{\sqrt{5}}$
   ஈ) $\frac{\sqrt{3}}{2}$

19. $\sin^{-1}\dfrac{x}{5} + \operatorname{cosec}^{-1}\dfrac{5}{4} = \dfrac{\pi}{2}$ எனில், $x$-ன் மதிப்பு
   அ) $4$
   ஆ) $5$
   இ) $2$
   ஈ) $3$

20. $|x| < 1$ எனில், $\sin(\tan^{-1} x)$-ன் மதிப்பு சமம்
   அ) $\frac{x}{\sqrt{1 - x^{2}}}$
   ஆ) $\frac{1}{\sqrt{1 - x^{2}}}$
   இ) $\frac{1}{\sqrt{1 + x^{2}}}$
   ஈ) $\frac{x}{\sqrt{1 + x^{2}}}$
