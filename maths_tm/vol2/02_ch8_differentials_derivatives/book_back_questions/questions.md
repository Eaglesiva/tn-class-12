### கொடுக்கப்பட்ட நான்கு மாற்று விடைகளிலிருந்து சரியான அல்லது மிகவும் ஏற்புடைய விடையினைத் தேர்ந்தெடுக்கவும்:

1. ஒரு வட வடிவ வார்ப்பின் ஆரம் $10$ செ.மீ. ஆரத்தின் அளவில் தோராயமாக $0.02$ செ.மீ பிழை உள்ளது எனில், அதன் பரப்பில் ஏற்படும் தோராய சதவீதப் பிழை
   அ) $0.2\%$
   ஆ) $0.4\%$
   இ) $0.04\%$
   ஈ) $0.08\%$

2. $31$-ன் $5$-ஆம் படி மூலத்தின் சதவீதப் பிழை தோராயமாக, $31$-ன் சதவீதப் பிழையைப் போல் எத்தனை மடங்காகும்?
   அ) $\frac{1}{31}$
   ஆ) $\frac{1}{5}$
   இ) $5$
   ஈ) $31$

3. $u(x, y) = e^{x^{2} + y^{2}}$ எனில், $\dfrac{\partial u}{\partial x}$-ன் மதிப்பு
   அ) $e^{x^{2} + y^{2}}$
   ஆ) $2xu$
   இ) $x^{2}u$
   ஈ) $y^{2}u$

4. $v(x, y) = \log(e^{x} + e^{y})$ எனில், $\dfrac{\partial v}{\partial x} + \dfrac{\partial v}{\partial y}$-ன் மதிப்பு
   அ) $e^{x} + e^{y}$
   ஆ) $\frac{1}{e^{x} + e^{y}}$
   இ) $2$
   ஈ) $1$

5. $w(x, y) = x^{y}, x > 0$ எனில், $\dfrac{\partial w}{\partial x}$-ன் மதிப்பு
   அ) $x^{y}\log x$
   ஆ) $y\log x$
   இ) $yx^{y-1}$
   ஈ) $x\log y$

6. $f(x, y) = e^{xy}$ எனில், $\dfrac{\partial^{2} f}{\partial x \partial y}$-ன் மதிப்பு
   அ) $xye^{xy}$
   ஆ) $(1 + xy)e^{xy}$
   இ) $(1 + y)e^{xy}$
   ஈ) $(1 + x)e^{xy}$

7. ஒரு கன சதுரத்தின் பக்க அளவு $4$ செ.மீ மற்றும் அதன் பிழை $0.1$ செ.மீ எனில், கன அளவு கணக்கீட்டில் ஏற்படும் பிழை
   அ) $0.4$ கன செ.மீ
   ஆ) $0.45$ கன செ.மீ
   இ) $2$ கன செ.மீ
   ஈ) $4.8$ கன செ.மீ

8. ஒரு கன சதுரத்தின் பக்க அளவு $x_{0}$-இலிருந்து $x_{0} + dx$ ஆக மாறும்போது, அதன் வளைபரப்பு $S = 6x^{2}$-இல் ஏற்படும் மாற்றம்
   அ) $12x_{0} + dx$
   ஆ) $12x_{0}\,dx$
   இ) $6x_{0}\,dx$
   ஈ) $6x_{0} + dx$

9. ஒரு கன சதுரத்தின் பக்க அளவு $1\%$ அதிகரிக்கும்போது அதன் கன அளவில் ஏற்படும் தோராய மாற்றம், பக்க அளவு $x$ மீட்டர் எனில்
   அ) $0.3x\,dx\,m^{3}$
   ஆ) $0.03x\,m^{3}$
   இ) $0.03x^{2}\,m^{3}$
   ஈ) $0.03x^{3}\,m^{3}$

10. $g(x, y) = 3x^{2} - 5y + 2y^{2}, x(t) = e^{t}$ மற்றும் $y(t) = \cos t$ எனில், $\dfrac{dg}{dt}$-ன் மதிப்பு
   அ) $6e^{2t} + 5\sin t - 4\cos t\sin t$
   ஆ) $6e^{2t} - 5\sin t + 4\cos t\sin t$
   இ) $3e^{2t} + 5\sin t + 4\cos t\sin t$
   ஈ) $3e^{2t} - 5\sin t + 4\cos t\sin t$

11. $f(x) = \dfrac{x}{x + 1}$ எனில், அதன் வகையீடு (differential)
   அ) $\frac{-1}{(x + 1)^{2}}\,dx$
   ஆ) $\frac{1}{(x + 1)^{2}}\,dx$
   இ) $\frac{1}{x + 1}\,dx$
   ஈ) $\frac{-1}{x + 1}\,dx$

12. $u(x, y) = x^{2} + 3xy + y - 2019$ எனில், $\left.\dfrac{\partial u}{\partial x}\right|_{(4, -5)}$-ன் மதிப்பு
   அ) $-4$
   ஆ) $-3$
   இ) $-7$
   ஈ) $13$

13. சார்பு $g(x) = \cos x$-ன் நேரியல் தோராய மதிப்பு $x = \dfrac{\pi}{2}$-இல்
   அ) $x + \frac{\pi}{2}$
   ஆ) $-x + \frac{\pi}{2}$
   இ) $x - \frac{\pi}{2}$
   ஈ) $-x - \frac{\pi}{2}$

14. $w(x, y, z) = x^{2}(y - z) + y^{2}(z - x) + z^{2}(x - y)$ எனில், $\dfrac{\partial w}{\partial x} + \dfrac{\partial w}{\partial y} + \dfrac{\partial w}{\partial z}$-ன் மதிப்பு
   அ) $xy + yz + zx$
   ஆ) $x(y + z)$
   இ) $y(z + x)$
   ஈ) $0$

15. $f(x, y, z) = xy + yz + zx$ எனில், $f_{x} - f_{z}$-ன் மதிப்பு
   அ) $z - x$
   ஆ) $y - z$
   இ) $x - z$
   ஈ) $y - x$
