### கொடுக்கப்பட்ட நான்கு மாற்று விடைகளிலிருந்து சரியான அல்லது மிகவும் ஏற்புடைய விடையினைத் தேர்ந்தெடுக்கவும்:

1. $\int_{0}^{\frac{2}{3}} \dfrac{dx}{\sqrt{4 - 9x^{2}}}$-ன் மதிப்பு
   அ) $\frac{\pi}{6}$
   ஆ) $\frac{\pi}{2}$
   இ) $\frac{\pi}{4}$
   ஈ) $\pi$

2. $\int_{-1}^{2} |x|\,dx$-ன் மதிப்பு
   அ) $\frac{1}{2}$
   ஆ) $\frac{3}{2}$
   இ) $\frac{5}{2}$
   ஈ) $\frac{7}{2}$

3. ஒவ்வொரு $n \in \mathbb{Z}$-க்கும் $\int_{0}^{\pi} e^{\cos^{2} x}\cos^{3}[(2n + 1)x]\,dx$-ன் மதிப்பு
   அ) $\frac{\pi}{2}$
   ஆ) $\pi$
   இ) $0$
   ஈ) $2$

4. $\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}} \sin^{2} x\cos x\,dx$-ன் மதிப்பு
   அ) $\frac{3}{2}$
   ஆ) $\frac{1}{2}$
   இ) $0$
   ஈ) $\frac{2}{3}$

5. $\int_{-4}^{4} \left[\tan^{-1}\left(\dfrac{x^{2}}{x^{4} + 1}\right) + \tan^{-1}\left(\dfrac{x^{4} + 1}{x^{2}}\right)\right] dx$-ன் மதிப்பு
   அ) $\pi$
   ஆ) $2\pi$
   இ) $3\pi$
   ஈ) $4\pi$

6. $\int_{-\frac{\pi}{4}}^{\frac{\pi}{4}} \left(\dfrac{2x^{7} - 3x^{5} + 7x^{3} - x + 1}{\cos^{2} x}\right) dx$-ன் மதிப்பு
   அ) $4$
   ஆ) $3$
   இ) $2$
   ஈ) $0$

7. $f(x) = \int_{0}^{x} t\cos t\,dt$ எனில், $\dfrac{df}{dx} =$
   அ) $\cos x - x\sin x$
   ஆ) $\sin x + x\cos x$
   இ) $x\cos x$
   ஈ) $x\sin x$

8. $y^{2} = 4x$ மற்றும் அதன் செவ்வகலத்திற்கும் இடையே உள்ள பரப்பு
   அ) $\frac{2}{3}$
   ஆ) $\frac{4}{3}$
   இ) $\frac{8}{3}$
   ஈ) $\frac{5}{3}$

9. $\int_{0}^{1} x(1 - x)^{99}\,dx$-ன் மதிப்பு
   அ) $\frac{1}{11000}$
   ஆ) $\frac{1}{10100}$
   இ) $\frac{1}{10010}$
   ஈ) $\frac{1}{10001}$

10. $\int_{0}^{\pi} \dfrac{dx}{1 + 5^{\cos x}}$-ன் மதிப்பு
   அ) $\frac{\pi}{2}$
   ஆ) $\pi$
   இ) $\frac{3\pi}{2}$
   ஈ) $2\pi$

11. $\dfrac{\Gamma(n + 2)}{\Gamma(n)} = 90$ எனில், $n$-ன் மதிப்பு
   அ) $10$
   ஆ) $5$
   இ) $8$
   ஈ) $9$

12. $\int_{0}^{\frac{\pi}{6}} \cos^{3} 3x\,dx$-ன் மதிப்பு
   அ) $\frac{2}{3}$
   ஆ) $\frac{2}{9}$
   இ) $\frac{1}{9}$
   ஈ) $\frac{1}{3}$

13. $\int_{0}^{\pi} \sin^{4} x\,dx$-ன் மதிப்பு
   அ) $\frac{3\pi}{10}$
   ஆ) $\frac{3\pi}{8}$
   இ) $\frac{3\pi}{4}$
   ஈ) $\frac{3\pi}{2}$

14. $\int_{0}^{\infty} e^{-3x}x^{2}\,dx$-ன் மதிப்பு
   அ) $\frac{7}{27}$
   ஆ) $\frac{5}{27}$
   இ) $\frac{4}{27}$
   ஈ) $\frac{2}{27}$

15. $\int_{0}^{a} \dfrac{1}{4 + x^{2}}\,dx = \dfrac{\pi}{8}$ எனில், $a$-ன் மதிப்பு
   அ) $4$
   ஆ) $1$
   இ) $3$
   ஈ) $2$

16. $y^{2} = x(a - x)$ என்ற வளைவரையில் அடைபடும் அரங்கத்தின் பரப்பை $x$-அச்சைப் பொருத்துச் சுழற்றுவதால் உருவாகும் திடப்பொருளின் கன அளவு
   அ) $\pi a^{3}$
   ஆ) $\frac{\pi a^{3}}{4}$
   இ) $\frac{\pi a^{3}}{5}$
   ஈ) $\frac{\pi a^{3}}{6}$

17. $f(x) = \int_{1}^{x} \dfrac{e^{\sin u}}{u}\,du, x > 1$ மற்றும் $\int_{1}^{3} \dfrac{e^{\sin x^{2}}}{x}\,dx = \dfrac{1}{2}[f(a) - f(1)]$ எனில், $a$ பெறக்கூடிய ஒரு மதிப்பு
   அ) $3$
   ஆ) $6$
   இ) $9$
   ஈ) $5$

18. $\int_{0}^{1} \left(\sin^{-1} x\right)^{2}\,dx$-ன் மதிப்பு
   அ) $\frac{\pi^{2}}{4} - 1$
   ஆ) $\frac{\pi^{2}}{4} + 2$
   இ) $\frac{\pi^{2}}{4} + 1$
   ஈ) $\frac{\pi^{2}}{4} - 2$

19. $\int_{0}^{a} \left(\sqrt{a^{2} - x^{2}}\right)^{3}\,dx$-ன் மதிப்பு
   அ) $\frac{\pi a^{3}}{16}$
   ஆ) $\frac{3\pi a^{4}}{16}$
   இ) $\frac{3\pi a^{2}}{8}$
   ஈ) $\frac{3\pi a^{4}}{8}$

20. $\int_{0}^{x} f(t)\,dt = x + \int_{x}^{1} tf(t)\,dt$ எனில், $f(1)$-ன் மதிப்பு
   அ) $\frac{1}{2}$
   ஆ) $2$
   இ) $1$
   ஈ) $\frac{3}{4}$
