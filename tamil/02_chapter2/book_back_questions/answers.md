- பொருத்துக வினா 1-ல் BrainKart-இன் வரிசை (குரங்குகள், பசுக்கள், பறவைகள், விலங்குகள்) மற்றும் repository வரிசை (குரங்குகள், விலங்குகள், பறவைகள், பசுக்கள்) வேறுபடுகின்றன. அதே பொருத்தங்களை repository வரிசைக்கு மாற்றியபோது விடை 3, 4, 2, 1 (ஆ) ஆகிறது.
- பிற விடைகள் உருவாக்கப்படவில்லை; அவற்றுக்கான இடங்கள் திறந்தவையாக வைக்கப்பட்டுள்ளன.


## வினா-வாரியான திறந்த விடை இடங்கள் — வரிசைச் சரிபார்ப்பு

கீழுள்ள ஒவ்வொரு எண்ணும் `questions.md`-இல் உள்ள அதே பிரிவு/வினா எண்ணுடன் ஒத்துப்போகும். இவற்றுக்கான விடைகள் இன்னும் எழுதப்படவில்லை.

- இலக்கணத் தேர்ச்சிகொள்: வினா 1, 2, 3, 4, 5, 6.
- நம்மை அளப்போம் — குறுவினா: வினா 1, 2, 3, 4.
- நம்மை அளப்போம் — சிறுவினா: வினா 1, 2, 3, 4.
- நம்மை அளப்போம் — நெடுவினா: வினா 1, 2, 3, 4.
- மொழியை ஆள்வோம் — கலைச்சொல் எடுத்தெழுதுதல்: 20 சொற்களுக்கான இடங்கள் 1–20.
- மொழியை ஆள்வோம் — இலக்கிய நயம்: வினா 1.
- மொழியை ஆள்வோம் — மயங்கொலிச் சொற்கள்: தொடர் 1, 2, 3.
- மொழியை ஆள்வோம் — அழைப்பிதழைப் பத்தியாக மாற்றுதல்: வினா 1.
- மொழியோடு விளையாடு — விழிப்புணர்வுக் கடிதம்: வினா 1.
- மொழியோடு விளையாடு — வட்டார வழக்குச் சொற்கள்: சொல் 1–20.
- மொழியோடு விளையாடு — நிற்க அதற்குத் தக: வினா 1.

ஒவ்வொரு திறந்த இடத்திற்கும் பின்னர் `விடைக்குறிப்பு`, `சாதாரண விடை`, `விரிவான விடை`, `Source` ஆகிய நான்கு பகுதிகளும் நிரப்பப்பட வேண்டும். புதிர் 1 மற்றும் 2-க்கு மட்டும் விடைகள் ஏற்கெனவே சேர்க்கப்பட்டுள்ளன.
